# YI:ON — 전이현 포트폴리오

전이현의 개인/채용용 포트폴리오 웹사이트입니다. 순수 HTML / CSS / Vanilla JavaScript로 제작되었습니다.

## 실행 방법

```bash
cd portfolio
python -m http.server 8080
```

접속: <http://localhost:8080>

## 구성

- `index.html`, `about.html`, `projects.html`, `journey.html`, `research.html`, `awards.html`, `archive.html`, `contact.html`, `chat.html` — 페이지
- `script.js`, `styles.css`, `theme.css`, `theme.js` — 공통 스크립트/스타일
- `data/` — 프로젝트·수상·활동·논문 데이터 및 인터랙티브 챗봇 엔진
- `assets/` — 이미지 리소스
- `DESIGN.md` — 디자인 토큰 및 컬러 시스템 문서
